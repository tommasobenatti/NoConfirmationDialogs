# Servers & sponsors

Meet the communities using **NCD — No Confirmation Dialogs**, created by [Tommaso Benatti](https://github.com/tommasobenatti).

## Featured server

| Server | Address | Relationship |
| --- | --- | --- |
| **MCExp** | **`mcexp.it`** · [Website](https://mcexp.it) | Creator's community and first server using NCD; in-game confirmation supplied by its owner. |

MCExp helped establish NCD's original use case: existing teleport/chat buttons should work with one click, including messages crossing a proxy and multiple backends.

## Join the showcase

Use NCD on your server? [Open a listing request](https://github.com/tommasobenatti/NoConfirmationDialogs/issues/new?title=Server%20showcase%20request) with the server name, public address/site, the NCD/platform versions used and confirmation that you are authorized to list it. Listings are reviewed by the maintainer. Do not include private connection details or player data.
